# Matrix Puzzle

A minimal, open-source matrix puzzle game also known as floor puzzle.

Play it in browser : https://matrix.fossgames.online/

## Features

- **Infinite Levels**: Procedurally generated puzzles for endless gameplay.
- **100% Offline**: Play anytime, anywhere without an internet connection.
- **No Ads & No Trackers**: Privacy-friendly with zero advertisements and analytics.
- **Lightweight**: Clean, distraction-free interface.
